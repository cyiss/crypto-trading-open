## 根本原因分析

### HTTP 521 错误详解

**HTTP 521 Web Server Down** 是由 AWS ELB（弹性负载均衡器）返回的，表示：

```
HTTP/2 521 
server: awselb/2.0
date: Sun, 25 Jan 2026 16:37:47 GMT
content-length: 0
```

**含义**：
- 负载均衡器无法连接到后端源服务器
- 后端服务器宕机、过载或不可用
- 不是应用层错误（没有错误信息）
- 是基础设施层错误

### 为什么不是其他原因

| 可能原因 | 排除理由 |
|--------|--------|
| **签名错误** | 公开 API 正常工作，说明基础设施和连接正常 |
| **认证失败** | 如果是认证问题，会返回 401/403 + 错误信息 |
| **接口不存在** | 新接口也返回 521，说明不是接口不存在 |
| **IP 限制** | 公开 API 可以访问，说明 IP 没有被限制 |
| **Passphrase 错误** | 已验证正确的 Passphrase，且公开 API 正常 |
| **时间戳错误** | 时间戳精度正确（毫秒级），公开 API 正常 |
| **客户端问题** | curl 和 Python 都返回相同的 521 错误 |

### 确定的事实

1. **代码实现正确** ✓
   - 签名算法：HMAC-SHA256（通过验证）
   - 请求格式：符合规范
   - 时间戳精度：毫秒级
   - Passphrase：正确

2. **网络连接正常** ✓
   - TLS 握手成功
   - SSL 证书有效（CN=*.weex.com，有效期至 2026-08-24）
   - HTTP/2 连接建立
   - 请求被正确发送

3. **公开 API 正常** ✓
   - 服务器时间：可获取
   - 合约信息：可获取
   - 行情数据：可获取

4. **私有 API 故障** ✗
   - 所有账户接口都返回 521
   - 所有交易接口都返回 521
   - 包括官方文档中的接口
   - 包括新接口和旧接口

### 根本原因

**WEEX 的私有 API 服务后端故障或不可用**

可能的具体原因：
1. **后端服务宕机** - 最可能
2. **后端过载** - 导致无法响应
3. **数据库连接故障** - 无法访问数据库
4. **网络故障** - 后端网络不可达
5. **维护中断** - 正在进行维护
6. **负载均衡器配置错误** - 路由配置问题
