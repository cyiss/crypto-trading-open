# WEEX 交易系统完整架构设计

## 系统概述

本系统通过油猴脚本（Tampermonkey）作为浏览器端执行层，与Python后端通过WebSocket进行双向通信，实现在WEEX交易所上的自动化交易功能。

## 核心模块设计

### 1. 网格交易系统 (Grid Trading)

**功能**：在设定价格区间内自动挂买卖单，通过价格波动赚取网格利润。

**配置参数**：
- `symbol`: 交易对 (如 BTCUSDT)
- `grid_type`: 网格类型 (normal/follow_long/follow_short)
- `lower_price`: 价格下限
- `upper_price`: 价格上限
- `grid_count`: 网格数量
- `order_amount`: 每格下单数量（张）
- `leverage`: 杠杆倍数

**工作流程**：
1. 获取当前价格
2. 计算网格价位
3. 在各价位挂限价单
4. 监控成交情况
5. 成交后在对向挂反向单

### 2. 刷量交易系统 (Volume Maker)

**功能**：通过快速双向交易增加交易量。

**配置参数**：
- `symbol`: 交易对
- `order_size`: 单笔订单大小（张）
- `interval`: 交易间隔（秒）
- `spread_tolerance`: 价差容忍度
- `daily_target`: 日目标交易量

**工作流程**：
1. 获取当前买一卖一价格
2. 同时挂买单和卖单
3. 等待成交
4. 循环执行

### 3. 套利监控与执行系统 (Arbitrage)

**功能**：监控WEEX与其他交易所的价差，发现套利机会时执行。

**配置参数**：
- `symbol`: 交易对
- `exchanges`: 监控的交易所列表
- `min_spread`: 最小价差阈值
- `order_size`: 套利单大小
- `execution_mode`: 执行模式 (manual/auto)

**工作流程**：
1. 从多个交易所获取价格
2. 计算价差
3. 当价差超过阈值时提醒或自动执行
4. 在低价交易所买入，高价交易所卖出

### 4. 网格波动率扫描器 (Volatility Scanner)

**功能**：扫描市场波动率，推荐适合网格交易的标的。

**配置参数**：
- `symbols`: 扫描的交易对列表
- `timeframe`: 分析时间周期
- `min_volatility`: 最小波动率阈值
- `max_volatility`: 最大波动率阈值

**工作流程**：
1. 获取多个交易对的K线数据
2. 计算各交易对的波动率
3. 按波动率排序
4. 推荐适合网格交易的标的

### 5. 价格提醒系统 (Price Alert)

**功能**：监控价格变动，达到设定条件时发出提醒。

**配置参数**：
- `symbol`: 交易对
- `upper_limit`: 价格上限
- `lower_limit`: 价格下限
- `change_threshold`: 变动阈值（百分比）
- `alert_method`: 提醒方式 (sound/notification)

**工作流程**：
1. 实时获取价格
2. 检查是否触发条件
3. 触发时发出提醒

## 通信协议

### 命令格式 (Python → 油猴)

```json
{
    "id": "uuid",
    "action": "place_order|cancel_order|get_price|get_account|...",
    "params": {
        // 具体参数
    },
    "timestamp": "ISO8601"
}
```

### 响应格式 (油猴 → Python)

```json
{
    "id": "uuid",
    "action": "place_order",
    "success": true,
    "result": {
        // 执行结果
    },
    "error": null,
    "timestamp": "ISO8601"
}
```

### 支持的命令

| 命令 | 描述 | 参数 |
|------|------|------|
| `get_price` | 获取当前价格 | - |
| `get_kline` | 获取K线数据 | - |
| `get_account` | 获取账户状态 | - |
| `get_positions` | 获取持仓信息 | - |
| `get_orders` | 获取挂单信息 | - |
| `place_order` | 下单 | type, side, price, quantity |
| `cancel_order` | 撤单 | order_id |
| `cancel_all` | 撤销所有订单 | - |
| `close_position` | 平仓 | symbol, type |
| `switch_symbol` | 切换交易对 | symbol |
