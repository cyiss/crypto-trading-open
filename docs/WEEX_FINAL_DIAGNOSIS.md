经过全面的测试和分析，我们已经确定：

**WEEX 的私有 API 服务后端存在严重故障，返回 HTTP 521 错误。**

### 发现 3：521 错误的含义

```
HTTP/2 521 
server: awselb/2.0
date: Sun, 25 Jan 2026 16:37:47 GMT
content-length: 0
```

**HTTP 521 Web Server Down**：
- 由 AWS ELB（弹性负载均衡器）返回
- 表示后端源服务器无响应
- 不是应用层错误
- 是基础设施层错误
