## 1. 测试目标

本次测试旨在验证通过**Tampermonkey (油猴) 脚本直接在浏览器端执行高频网格交易**的可行性与稳定性。此方案作为 `Selenium WebDriver` 方案失败后的替代方案，目标是跑通完整的下单、监控流程，并为后续的自动化交易提供坚实的基础。

## 2. 测试方法

测试核心是 `weex_grid_tampermonkey.js` 脚本，该脚本被设计为可以直接注入到 WEEX 交易页面并执行。

### 2.1. 核心脚本: `weex_grid_tampermonkey.js`

该脚本包含以下核心功能：

- **配置模块**: 允许轻松调整网格数量、间距、下单量等参数。
- **DOM 操作**: 封装了与 WEEX 页面元素的交互，如输入价格、数量和点击按钮。
- **订单逻辑**: 自动计算买卖网格的价格点，并按顺序执行下单。
- **状态管理与日志**: 实时记录脚本运行状态、已下订单和统计数据。
- **全局 API**: 暴露 `window.weexGrid` 对象，允许从浏览器控制台手动触发交易、获取状态或重置。

### 2.2. 执行流程

1.  **导航**: 使用浏览器工具打开 [WEEX BTC/USDT 永续合约页面](https://www.weex.com/zh-CN/futures/BTC-USDT)。
2.  **注入**: 将 `weex_grid_tampermonkey.js` 脚本内容通过浏览器开发者工具的控制台注入到当前页面。
3.  **执行**: 在控制台调用 `weexGrid.start()` 函数来启动网格交易程序。
4.  **监控**: 通过查看页面上的“当前委托”列表和控制台日志来监控订单的执行情况。
